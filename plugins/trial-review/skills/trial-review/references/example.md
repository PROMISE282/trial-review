# 출력 예시 (무료판)

요청: "AI가 로그인 코드를 고쳤어. 재판해줘" — A 토큰 만료 7일→60일, B 에러 문구 통일, C 로그인 시 전체 사용자 목록 응답(코드는 붙여넣지 않음).

**결론: 채택 후보 1, 조건부 0, 보류·기각 2, 판단 불가 0 (모의 투표).** C는 요청에 적힌 변경만으로 다른 사람 정보가 노출됩니다.

**머리말** 편성: 서버·API 쟁점이라 A·B·C 모두 PM, BE, 보안, QA, 운영 / 한계: 모의 투표이며 독립 표본이 아님, 무료판(1차만, 배심원 5명 고정, 법무 관점 없음, 채팅 텍스트만 평가), 기존 검증 없음, 자료 없이 일반 지식 판단

| 안건 | 검사 주장 | 현행 변호 | 직무별 투표 | 찬성 | 쟁점 |
|---|---|---|---|---|---|
| A 만료 60일 | 로그인 유지가 편해짐 | 짧을수록 탈취 피해가 작음 | × × ○ ○ ○ | 3/5 | 보안 ×: 요청에 적힌 최대 유효기간 60일(차단급). BE ×: 롤백 시 기존 토큰 처리 불명. 일반 지식 판단 |
| B 문구 통일 | 계정 존재 노출 방지 | 사용자가 원인을 모름 | ○ ○ ○ ○ ○ | 5/5 | 일반 지식 판단 |
| C 전체 목록 응답 | 편의 | 없음 | × × × × × | 0/5 | × 5명 같은 이유: 요청에 적힌 변경이 다른 사용자 정보 노출(차단급) |

| 순위 | 안건 | 찬성 | 상태 |
|---|---|---|---|
| 1 | B | 5/5 (100%) | 채택 후보 |
| 2 | A | 3/5 (60%) | 보류 (차단급, 표수는 조건부) |
| — | C | 0/5 (0%) | 기각 (차단급) |

**판결** B 채택 후보: 위험이 작고 반대가 없습니다. A 보류(차단급): 해소 조건은 만료 30일 미만, 또는 절대 만료 상한 명시. C 기각(차단급): 응답에서 다른 사용자 정보를 빼야 다시 상정할 수 있습니다.

어떤 안건을 채택할지는 직접 정해 적용해 주세요. 파일을 읽고 적용 후 2차 평가를 하는 기능은 Pro판에서 지원합니다.
